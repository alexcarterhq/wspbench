The first public development archive contained tasks, weights, references and practice files, but its directory layout did not match the CLI loader and it omitted the scoring arrays required for replay. It was an inspection export, not a complete executable reproduction. The preview replaces that path with public development grading fixtures, manifests and a dedicated CPU replay command. Active held-out fixtures and generation metadata are not released.

Earlier public CPU summaries were produced under earlier harness revisions; one older summary also used an earlier suite. They must not be described as current validation evidence for the eighteen-session pilot. The preview's matching summaries are exported from the measured cohort's validation outputs and bound to its source/data digests.

Earlier OpenAI engineering runs exposed separate retry layers and automatic reasoning-summary capability probes outside reported evaluation usage. The measured preview explicitly disables SDK retries, Inspect retries and those probes, with capped streamed requests and the standard service tier. Fake-transport tests check the request count and settings. The eighteen measured sessions were independently checked for request/configuration, usage, artifacts, grading and access compliance. Older experiments use different protocols or lack comparable accounting and are excluded from the preview comparison.

An earlier v0.1 cost calculation omitted cached-input categories. It was corrected through append-only operational evidence. The preview prices uncached input, cache reads, cache writes and output separately. Reported reasoning tokens are included in output and are never charged a second time. Historical unknown charges remain reserved operationally and are not substituted with zero or included in the new cohort estimate. The reported $2.2581618 is an estimate for the eighteen-session cohort, not total project spending or a provider invoice.
